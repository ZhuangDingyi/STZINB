

# STZINB
Código fuente de la implementación de la red de distribución binomial negativa con exceso de ceros espacio-temporal para la predicción de la demanda de viajes.

Ejecute *python main_zero_inflated.py* para entrenar el modelo y generar predicciones y evaluaciones del mismo utilizando *python test_zero_inflated.py*. Recuerde reemplazar los archivos de datos y los archivos de salida correspondientes.
